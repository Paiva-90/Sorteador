
🎲 Sorteador - Responsivo
![Preview do Projeto](./assets/projetosortear.png)

Projeto simples e responsivo para sortear um número aleatório.

🔗 *Site no ar:* https://paiva-90.github.io/Sorteador/

📱 Preview
Funciona 100% no celular e no computador, com fundo temático de loteria.

✨ Como funciona
1. Digite o número inicial em "Do numero"
2. Digite o número final em "ate"
3. Clique em "Sortear"
4. O resultado aparece no meio (R)

🚀 Tecnologias usadas
- HTML5
- CSS3 (Flexbox + Responsivo)
- JavaScript
- GitHub Pages
